## О библиотеке

- **Библиотека:** Nanostores
- **Исследуемая версия:** 1.5.5

## Демонстрационный проект

Nanostores Reactive Lab — небольшое интерактивное приложение-корзина. Пользователь меняет цену, количество, налог и состав заказа, а приложение показывает, как исходные атомы приводят к обновлению `$subtotal` и `$total`. Отдельный эксперимент позволяет считать вызовы `computed` и `listen`, отключать подписчика и сравнивать обновление двух зависимостей с `batch` и без него. Журнал на странице группирует логи по действиям.

## Требования и запуск

Требуются Node.js 20 или новее и npm. Из корня этого проекта выполните:

```sh
npm install
npm run dev
```

Откройте локальный адрес, напечатанный Vite в терминале. Production-сборка:

```sh
npm run build
npm run preview
```
